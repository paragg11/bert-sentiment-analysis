# BERT Sentiment Analysis

Binary sentiment classification using fine-tuned BERT
and the IMDb movie review dataset.

## Features
- BERT tokenization
- Positive and negative review classification
- Evaluation using accuracy, precision, recall and F1-score

## Model
google-bert/bert-base-uncased

## Initial Results
Accuracy: 84.2%
Precision: 81.75%
Recall: 87.40%
F1-score: 84.48%

Results are from a 500-review test sample.
